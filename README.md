# D0174 分區運營平台

D0174 是獨立的分區運營前端，保留五個主模組：管理總覽、人員檔案、團隊出勤、離職管理、報表中心。新人檔案與新人入職流程收在「人員檔案」的子功能內。

## 目前功能

- 管理總覽：月份切換、出勤／新人／離職摘要、最新動態與快速入口。
- 人員檔案：團隊名單（搜尋、分組、修改、刪除、CSV 導出、JSON 匯入）、團隊檔案、新人檔案、新人入職流程。
- 團隊出勤：月份選擇、人員出勤、年度／月度欄位、分析評估、會議記錄、請假／簽到入口、出勤導出。
- 離職管理：月份篩選、離職申請、通知期、交接、物品歸還、權限回收、完成進度與導出。
- 報表中心：已移除既有 D0133 報表表格，只保留 D0174 功能選擇、月份選擇與 CSV／Excel／PDF 上傳入口，並可管理上傳記錄。

## 獨立資料模型

前端使用 `localStorage` 的 `d0174-platform-state-v1` 保存資料，所有狀態均固定帶有 `divisionId: "D0174"`。初始資料集為空；匯入 JSON 時若 `divisionId` 不是 `D0174` 會拒絕。

## 本機預覽

```bash
python3 -m http.server 4174 --directory dist
```

瀏覽器開啟 `http://127.0.0.1:4174/`。

## 目錄

- `dist/index.html`：入口頁
- `dist/app.css`：介面樣式
- `dist/app.js`：視圖、表單、匯入／匯出與獨立資料模型
- `DATA_MODEL.md`：資料欄位與隔離規則
- `D0174_PARITY.md`：D0133 參考流程與 D0174 對應範圍
